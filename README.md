# 브릿지포 (Bridge4)

부산 지역 외국인 유학생·근로자를 위한 **채용공고 근로조건 분석 · 권익 보호 AI**.

한국어 공고는 임금 표기가 뒤섞여 적정 수준을 비교하기 어렵고, 불리한 조건은 지원한
뒤에야 드러난다. 이 앱은 두 가지를 한 화면에서 답한다.

| | 질문 | 방법 |
|---|---|---|
| **ML** | 이 조건이면 얼마가 적정한가 | LightGBM 분위수 회귀 + CQR 보정 → 80% 구간 |
| **LLM** | 이 공고에서 무엇을 물어야 하는가 | 근로조건 7종 판정 → 모국어 확인 질문 |

## 화면

| 탭 | 내용 |
|---|---|
| 💬 공고 물어보기 | 공고를 붙여넣고 **아무 언어로 질문**. 질문한 언어로 답한다 |
| 📚 수집 공고 | 이미 진단해 둔 5,168건. 사전 계산본이라 API 비용 없음 |
| 📈 모델 성능 | 성공기준 3종 지표와 한계 |

**6개 언어** — 한국어 · English · 简体中文 · Tiếng Việt · 日本語 · Español.
사이드바에서 언어를 고르면 화면 전체가 바뀐다.
일부러 한국어로 남기는 것 — 고용주에게 보여줄 질문 문장, 공고 인용 원문, '모델 성능' 탭.

## 성과

| 성공기준 | 목표 | 결과 |
|---|---|---|
| 임금 구간 커버리지 | 80% | **81.3%** (CQR 보정 없으면 56.9%) |
| 근로조건 탐지 F1 | 0.80 | **micro 0.894 / macro 0.893** (대표 5라벨) |
| 용어 보존율 | 90% | **94.3%** (중국어, 필수용어 105회) |

## API 키

**Secrets 에 키를 넣지 않는 편을 권한다.** 넣으면 링크를 아는 누구나 그 크레딧을 쓴다.
지금 구조는 사용자가 사이드바에 자기 키를 넣는 방식이고, 키가 없어도
임금 예측과 사전 계산된 중국어 진단 83건은 모두 보인다. 대화만 키가 필요하다.

굳이 넣으려면 **Settings → Secrets** 에:

```toml
OPENAI_API_KEY = "sk-..."
```

> `.env` 는 저장소에 올리지 않는다. `.gitignore` 에 등록되어 있고,
> `prepare_deploy.py` 도 복사하지 않는다.

## 조용히 틀리기 쉬운 지점

실제로 겪은 것들이다. 코드에 방어를 넣어 두었다.

- **CQR 보정폭을 빼먹으면 커버리지가 81% → 57%** 로 무너진다. `meta.json` 의
  `cqr_widen_log` 를 log 공간에서 q10 에 빼고 q90 에 더한 뒤 `expm1` 한다.
- **범주형은 학습 범주 순서를 그대로** 써야 한다. LightGBM 은 범주를 정수 코드로
  다루므로 `meta.json` 의 `categories` 로 `pd.Categorical` 을 강제한다.
  부스터의 `feature_name()` 과 meta 순서를 시작 시 대조하고 어긋나면 멈춘다.
- **결측을 채우면 안 된다.** pandas 3 의 `astype(str)` 은 NaN 을 `"nan"` 으로 바꾸지
  않으므로, 학습은 CSV 의 NaN 을 결측으로, 문자열 `정보없음` 을 별개 범주로 다뤘다.
  `fillna("")` 를 했다가 예측이 10,715원 → 10,700원으로 어긋난 적이 있다.
- **최저임금 판정에 q10 을 쓰면 안 된다.** q10 은 정의상 분포 하단이라 저임금 직종
  대부분이 미달로 나온다(학습 3,674건의 65%). 표기 임금이 있으면 환산 시급으로
  확정 판정하고, 없을 때만 중앙값 q50 으로 판정한다.
- **LightGBM 은 Windows 에서 비ASCII 경로를 열지 못한다.** `model_file=` 대신
  `model_str=` 로 파일을 Python 이 읽어 넘긴다.

## 한계 — 함께 읽어야 하는 것

- **정답지는 47건이고 '사람 검수 100건' 이 아니다.** LLM 2종(GPT-5.4 · Gemini)
  교차 라벨 + 불일치 전량 판정으로 만들었다. 셀 329개의 확정 근거는
  `reports/llm/adjudication_log.csv` 에 있다 (일치 258 / 가이드 54 / 사람 17).
- **양성 사례가 적다.** 라벨당 TP+FN 이 1~10건이다.
- **`사회보험_미기재` F1 0.987 은 성능이 아니다.** 정답지가 규칙으로 결정되고
  모델도 같은 규칙을 받았다. 대표지표에서 제외했다.
- **LLM 진단 커버리지 상한은 61.4%** — 공고 본문 보유율이 그만큼이다.
- **q50 R² 는 0.283.** 점 추정 정확도는 낮으므로 구간으로 제시하고,
  신뢰도 '매우낮음' 은 구간을 아예 숨긴다.
- **대화 답변은 생성 모델의 출력이다.** 공고에 없는 내용은 '없다'고 답하도록 했지만,
  중요한 조건은 항상 공고 원문과 함께 확인해야 한다.
